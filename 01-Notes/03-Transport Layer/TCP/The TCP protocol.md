#review2

- TCP is a {{[[Transport layer|transport]]}} [[Layers|layer]] [[Protocol]]
- TCP is an acronym for _Transmission Control Protocol_
- Specified in several RFCs:
	- RFCs 793, 1122, 1323, 2018 and 2581
- TCP is a {{connection}}-oriented protocol.
- TCP allows bidirectional data exchange.
- It is a reliable protocol [[TCP reliability]]
- It prevents overflowing both the receiver [[TCP flow control]] and the network [[TCP congestion control]]
