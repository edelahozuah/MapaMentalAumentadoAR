#review2

- DNS: {{Domain Name System}}
- It is a {{distributed database}}
	- Implemented in a set of servers organized {{hierarchically}}
- Directory service for Internet resources
	- Resources:
		- IP addresses
		- Host information
		- Canonical hostnames
		- Simplified hostnames (aliases)
		- Mail server names
		- DNS server names
		- etc
- It provides service to other network applications, and does not interact with the user directly
- The protocol that allows information to be exchanged is also called DNS
