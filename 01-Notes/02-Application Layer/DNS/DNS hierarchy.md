#review2 

- It follows an organizational structure
- Components (labels) of a domain name
- A name is written from right to left, starting with the root, then the top-level domain and so on; the further to the left, the more specific, until reaching the identifier of a host name within a domain.
	- For example:
		- es: domain of Spain (top-level domain, TLD).
		- uah.es: domain of the UAH within the ES domain
		- aut.uah.es: domain of the Department of Automation (Automática) within that of the UAH (which is within that of ES)
		- www.aut.uah.es: identifies the host www that is within the domain aut.uah.es.
