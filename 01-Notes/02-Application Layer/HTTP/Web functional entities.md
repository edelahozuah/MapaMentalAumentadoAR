 - Web client
	 - Comprises:
		 - User agent.
			 - {{Software that acts as the interface between the user and the Web application.}}
			 - Allows pages to be downloaded and displayed, and their contents to be “browsed”.
			 - Offers various configuration features.
		 - HTTP client.
			 - {{Communication software that implements the HTTP client side.}}
	 - Best-known browsers:
		 - Microsoft Edge.
		 - Firefox.
		 - Chrome.
		 - Safari, and others…
 - Web server
	 - Comprises three functional entities:
		 - File access software.
		 - Database.
			 - Stores objects.
			 - Each object is addressable through the corresponding URL.
		 - HTTP server.
			 - {{Communication software that implements the HTTP server side.}}
	 - Best-known web servers:
		 - Apache.
		 - MS Internet Information Server (IIS).
