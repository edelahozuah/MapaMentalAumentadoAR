- What is HTML?
	- HTML stands for "HyperText Markup Language".
	- It is the standard language used to create and design web pages.
	- User agents (see [[Web functional entities]]) process these documents and present them to the user in their browser.
- Basic elements of HTML
	- **Tags**: used to mark up the content and structure of a web page.
	- **Attributes**: provide additional information to tags.
- Basic structure of an HTML document
	- \<!DOCTYPE html\>: Document type declaration.
	- \<html\>: Root element of the HTML document.
	- \<head\>: Document head.
	- \<title\>: Page title shown in the browser tab.
	- \<body\>: Document body, where the visible content is placed.
- Common HTML tags:
	- \<h1\> to \<h6\>: Headings of different levels.
	- \<p\>: Paragraphs of text.
	- \<a\>: Links to other pages or resources.
	- \<img\>: Images.
	- \<ul\> and \<li\>: Unordered lists.
	- \<ol\> and \<li\>: Ordered lists.
	- \<div\>: Generic container for grouping elements.
	- \<span\>: Generic container for styling inline text or elements.
	- \<br\>: Line break.
	- \<hr\>: Horizontal line.
