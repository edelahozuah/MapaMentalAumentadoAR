- Messages generated by the server in response to a client's request.
- The first line of response messages is called the _status line_, and it consists of three fields separated by spaces:
	- _Version_ of the HTTP protocol.
	- _status code_: see below.
	- _phrase_ is a textual description of the status code.
- _Status codes_ represent the possible responses a server can return. It is a three-digit numeric value, where the first digit indicates the **type** of code, which can be:
	- **1xx**: informational, provisional response.
	- **2xx**: success in fulfilling the request.
	- **3xx**: redirect the request, further action required.
	- **4xx**: client error.
	- **5xx**: server error.
- Some of the most commonly used codes are:
	- 200 (phrase: OK). 
	- 201 (phrase: Created)
	- 301 (phrase: Moved permanently)
	- 401 (phrase: Unauthorized)
	- 404 (phrase: Not Found)
