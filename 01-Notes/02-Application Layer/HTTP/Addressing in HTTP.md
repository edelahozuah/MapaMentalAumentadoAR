#review2

- Based on a URL: Uniform Resource Locator.
	- Element used for addressing/identifying resources.
- Parameters of a URL:
	1. Service identifier (protocol).
	2. Domain name of the server host.
	3. Path to the object.
	4. Object name.
- URL syntax.
	- The characters “://” separate the first parameter (protocol) from the second (domain name).
	- The character “/” separates the remaining parameters from one another.
- Example: http://www.escuela.es/dptotic/imagen1.jpg

| http | :// | www.escuela.es | / | dptotic | / | imagen1.jpg |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| (1) | sep | (2) | sep | (3) | sep | (4) |
