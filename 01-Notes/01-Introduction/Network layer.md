- The network layer enables {{datagrams sent by a host to reach the destination host}} by traversing intermediate devices called {{routers}}.
- Each device connected to the network must be uniquely[^1] identified. In IP this is called the {{[[IP address]]}}.

[^1]: "Unívoca" (unique) correspondence according to the RAE (Royal Spanish Academy) dictionary: 1. f. Math. Relation between two sets whereby every element of the first set is mapped to a single element of the second.
