- The Internet model divides the problem of transmission between two network devices into five layers or levels:
	- 5 - Application
	- 4 - Transport
	- 3 - Network
	- 2 - Link
	- 1 - Physical
- Some authors consider that this model has four layers, merging the last two into a single one called the subnet layer (or network access layer, again depending on the author).
- This model is generally known as the TCP/IP model, although that is not entirely correct, since TCP and IP are simply transport and network layer protocols, so the name does not cover all the protocols that can be used. It is only called that because they are the most widely used protocols in those layers.
