- Instead of tackling the problem of transmitting information between devices as a whole, the "[Divide and Conquer](https://en.wikipedia.org/wiki/Divide-and-conquer_algorithm)" strategy is used, in which the problem is divided into different parts (layers or levels), each with a specific functionality that differs from the rest.
- Layer or level: {{a set of well-defined functions aimed at solving a particular problem}}
- Logically, layers are represented one on top of another: the lower layer provides {{services[^1]}} to the layer immediately above.

![[Modelo-de-capas.png]]


[^1]: A service is a set of operations (primitives) that a layer provides to the layer immediately above it.
